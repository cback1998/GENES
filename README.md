# GENES

这个仓库用于存放和演示基因组与群体遗传学分析的示例代码、数据和文档。

## 内容

- `scripts/`: 分析脚本与可视化脚本（Python 等）。
- `data/`: 示例数据。
- `web/`: 项目相关的网页演示。
- `docs/`: 项目概览和说明文档。

欢迎在此基础上进行扩展和补充。

## 新增示例：修仙文字冒险

在 `scripts/xiuxian_game.py` 中提供了一个轻量的命令行修仙冒险小游戏，包含打坐修炼、探索秘境、炼丹、服丹等互动选项。

运行方式：

```bash
python scripts/xiuxian_game.py
```
